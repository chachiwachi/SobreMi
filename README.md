# SobreMi

Página personal estática con mis proyectos de GitHub, publicada en **https://julio.biz** con GitHub Pages.

- `index.html`: la página
- `css/estilo.css`: estilos (modo claro y oscuro automático)
- `js/repos.js`: carga mis repositorios públicos desde la API de GitHub
- `CNAME`: dominio personalizado para GitHub Pages

Sin dependencias ni compilación: cualquier cambio que se suba a `main` se publica solo.
